## ✨ Fitur Utama
1. **Struktur Semantik HTML5:** Menggunakan elemen `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, dan `<footer>` secara terstruktur.
2. **Desain Responsif (Tailwind CSS + Custom CSS):** Tampilan rapi di layar Desktop, Tablet, maupun Mobile.
3. **Kalkulator Estimasi Biaya Proyek:** Menghitung estimasi biaya pembuatan website secara *real-time* berdasarkan jenis proyek, jumlah halaman, dan tenggat waktu.
4. **Interaktivitas UI & Manipulasi DOM:**
   - *Dark Mode / Light Mode Toggle*
   - *Filter Kategori Proyek* secara dinamis tanpa *reload* halaman
   - *Validasi Form Kontak* dengan umpan balik langsung pada halaman
